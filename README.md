# BillGames
Billing panel, statistics and progress tracking, plugin integration, and an in-game store—compatible with all RCON-enabled servers.
Can be adapted to any game that uses RCON. Stop using generic control panels and build your own for maximum flexibility, if the game is worth the effort.
